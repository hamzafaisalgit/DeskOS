# DeskOS roadmap

1. **Desktop Foundation — implemented; final verification recorded in PROGRESS.md.** Shell, centralized windows, registry, dock, launcher, command search, shortcuts, context menus, themes, six wallpapers, settings, notifications, versioned preferences, scratchpad Notes, DeskShell, safe Calculator, honest Files shell and initial tests.
2. **Virtual Computer — implemented.** Shared virtual filesystem, IndexedDB, Files operations, import/export, trash and associations.
3. **Core Integrated Applications — implemented.** Shared-file Notes, fuller Terminal, Code Studio, integrated Calculator and scratchpad migration.
4. **Creative & Media Suite — implemented.** Music, Photos, Video, PDF, Canvas and filesystem integrations.
5. **Spaces — not started.** Named desktops, per-space layouts, supported app sessions and snapshots.
6. **Portability and Recovery — not started.** Validated Capsule backups, revisions, restore points, migrations and Time Machine.
7. **Application Platform — not started.** App Center, SDK, isolated applications and capability permissions.
8. **Production Readiness — not started.** Broader cross-browser/accessibility/performance testing, PWA, storage hardening and deployment readiness.

The next implementation phase is Phase 5. Do not introduce a parallel filesystem inside any application.
